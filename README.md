## Решение: установка и запуск

Нужен **Python 3.10 или новее** (проверено на 3.11 и 3.14). Сторонних библиотек нет, `pip install` не нужен.

1. Распакуйте архив и перейдите в папку проекта:

   ```bash
   cd candidate-B
   ```

2. Постройте отчёт на дату. На Windows вместо `python` можно писать `py`, на macOS/Linux - `python3`:

   ```bash
   python main.py --date 2026-11-10
   ```

   Дату можно указать и по-русски: `python main.py --date 10.11.2026`. События, датированные днём отчёта, учитываются.

3. Результат появится в папке `output/`. Краткая сводка также печатается в консоль.
   - `output/report_2026-11-10.csv` - по каждой работе: цена, выплачено, осталось оплатить, в очереди; итоги по договорам; раздел «ЗАМЕЧАНИЯ» с расхождениями, переплатами и нераспределёнными платежами;
   - `output/payments_2026-11-10.csv` - каждый платёж: статус на дату и куда распределён.

Другие примеры:

```bash
python main.py --date 2026-11-12
```

```bash
python main.py --date 2026-09-05 --out reports
```

```bash
python main.py --date 2026-11-10 --csv-style standard
```

```bash
python main.py --date 2026-11-10 --data path/to/other/data
```

Отчёт на 12.11 показывает переплату по D-2, а отчёт на 05.09 - момент до возврата P-2.

Параметры:

| Параметр | Что делает |
|---|---|
| `--date` | дата отчёта, обязательно |
| `--data` | папка с CSV, по умолчанию `data/` проекта |
| `--out` | папка для отчётов, по умолчанию `output/` проекта |
| `--csv-style` | `excel` (по умолчанию: `;`, десятичная запятая, UTF-8 с BOM - открывается двойным щелчком в Excel с русскими настройками) или `standard` (`,` и точка) |

Справка: `python main.py --help`. Коды выхода: 0 - успех, 2 - ошибка в аргументах или исходных данных (сообщение указывает файл и строку), 3 - файл отчёта открыт в Excel и не может быть перезаписан.

Тесты (стандартный `unittest`):

```bash
python -m unittest -v
```

Файлы решения:

| Файл | Что там |
|---|---|
| `main.py` | точка входа |
| `contract_report/loader.py` | чтение и проверка CSV, суммы в `Decimal` |
| `contract_report/engine.py` | статусы на дату, распределение платежей, проверки и замечания |
| `contract_report/export.py` | CSV-отчёты и сводка в консоль |
| `contract_report/cli.py` | разбор параметров командной строки |
| `tests/` | автотесты: реальные данные на разные даты, синтетические случаи, CSV и CLI |
| `output/` | готовые отчёты на 10.11.2026 |
| `DECISIONS.md` | решения и допущения |
| `NOTE_FOR_ACCOUNTANT.md` | записка бухгалтеру |

Исходные файлы в `data/` программа только читает.
